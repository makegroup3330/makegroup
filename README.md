운영 화면은 2026-10-17에 적용한 새 디자인입니다. 프로젝트 분류 재검토, 스튜디오 위치 지도, 은은한 건축 선화 배경을 반영했습니다. 이전 홈페이지는 별도 저장소 `makegroup-backup`의 GitHub Pages에 보관합니다. 개선안은 `preview/`에서도 확인할 수 있습니다. 기존 PL 홈페이지 저장소 `plhomepage`는 수정하거나 디자인 참고 자료로 사용하지 않았습니다.

## 개선안 적용 / 기존 화면 복원

GitHub에 `makegroup3330` 계정으로 로그인한 뒤 아래에서 실행합니다.

https://github.com/makegroup3330/makegroup/actions/workflows/site-pages.yml

1. **Run workflow**를 누릅니다. Branch는 `main`을 선택합니다.
2. 실행할 버전을 선택합니다.
   - `keep`: 현재 운영 화면 유지, 미리보기와 함께 다시 게시
   - `apply_design`: 개선안을 운영 홈페이지에 적용
   - `restore_original`: 보관한 기존 화면으로 복원
3. **Run workflow**를 눌러 실행합니다. 초록색 성공 표시가 나온 뒤 홈페이지를 확인합니다.

적용과 복원은 GitHub Pages 배포 시간이 필요하므로 몇 분 걸릴 수 있습니다. 별도 도메인 변경은 필요 없습니다. 미리보기는 계속 유지됩니다. 한 번의 배포가 완료되면 해당 버전의 페이지와 이미지가 함께 교체됩니다.

## 검색 노출 / 문의

미리보기 페이지에는 `noindex`를 넣고 `robots.txt`에서 `/preview/`를 제외했습니다. 개선안을 운영 화면으로 적용하면 본문 페이지의 검색 허용 설정, 운영 도메인의 canonical과 사이트맵을 함께 적용합니다.

운영 홈페이지와 미리보기의 프로젝트 문의 양식은 FormSubmit으로 직접 전송합니다. 수신 주소는 `Makegroupcg@naver.com`입니다. 방문자는 전송 후 스팸 방지 보안 확인을 완료해야 합니다. 이메일 주소 링크를 누르면 기존처럼 이메일 앱에서 작성할 수도 있습니다.

### 문의 메일 전송 — 2026-10-18

- 수신 주소: `Makegroupcg@naver.com`
- 전송 방식: `https://formsubmit.co/Makegroupcg@naver.com`으로 HTML POST. 이메일 앱이나 비밀 API 키가 필요 없습니다.
- 이름/회사명, 회신 이메일, 문의 내용을 전송합니다. 방문자에게 외부 전송 서비스 이용 사실을 표시합니다.
- FormSubmit 기본 보안 확인(reCAPTCHA)을 유지합니다. 추가 숨김 스팸 필드를 사용합니다.
- JavaScript가 없어도 전송할 수 있고, 필수 입력/이메일 형식 검사와 중복 클릭 방지를 제공합니다. 서비스 오류 시 뒤로 돌아오면 입력 내용을 유지하고 다시 전송할 수 있습니다.
- 개발 주소 인증과 별개로 실제 `makegroup.co.kr/preview/contact.html`에서 인증을 요청했고, 2026-10-18 사용자가 **makegroup.co.kr 인증 완료**를 확인했습니다. 인증 후 재전송은 **Almost There** 보안 확인 화면으로 진행되었습니다. 이어 사용자가 보안 확인을 완료했으며 서비스의 **Thanks! / The form was submitted successfully** 응답을 확인했습니다. 사용자가 확인 코드 `MAKE-MAIL-20261018` 테스트 문의의 네이버 메일 수신도 확인했습니다.
- 로컬 주소 `127.0.0.1:4177`은 개발 검사에만 사용했습니다. 운영 양식은 GitHub Pages에서 제공되고 외부 전송 서비스로 POST하므로 개발 서버 실행 여부와 관계없이 작동합니다. 수신 주소나 사이트 도메인을 바꾸면 해당 주소의 인증을 다시 확인합니다.
- 직접 이메일 링크와 전화 문의도 유지합니다. 첨부파일, 자동 회신, 문의 저장함은 이번 기능에 포함하지 않습니다.
- 서비스 안내: https://formsubmit.co/documentation / https://formsubmit.co/help

Wix 서버의 댓글·조회수·로그인·결제 처리는 포함되지 않습니다.
